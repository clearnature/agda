Release notes for Agda version 2.9.0-nightly
============================================

This file is not an upstream release note.  It documents the local
`2.9.0-nightly` version label of this fork, and how that binary is built
and installed.

Version label
-------------

`agda --version` and `agda --numeric-version` report `2.9.0-nightly`.
The label is produced by `src/setup/Agda/VersionCommit.hs`:

    versionWithCommitInfo = version ++ "-nightly"

Upstream appends the git commit hash there instead, so this build does
not report a commit hash.  The `version` part still comes from the Cabal
version (`versionBranch Paths_Agda`), i.e. `Agda.Version` is unchanged,
and `--help` keeps reporting `2.9.0`.

The label does not affect the interface-file version, which is the
hard-coded `currentInterfaceVersion` in `Agda.TypeChecking.Serialise`,
so already written `.agdai` files stay valid.

Base revision
-------------

`git describe` is `nightly-294-g1705389c69`: the merge of upstream
`5155862` into this fork's `master`, which is 138 commits ahead of
`origin/master`.

Build
-----

    stack --system-ghc build Agda --no-haddock --test --no-run-tests \
      --flag Agda:optimise-heavily --work-dir=.stack-work \
      --flag Agda:debug --no-library-profiling --flag Agda:enable-cluster-counting \
      --ghc-options "+RTS -A128M -M6G -RTS"

`--system-ghc` is required here: without it stack uses its own
`ghc-tinfo6-9.14.1` and builds into the stale
`.stack-work/dist/x86_64-linux-tinfo6/` tree instead of
`.stack-work/dist/x86_64-linux/`.

Install
-------

The binary is installed as `/opt/agda/2.9.0/bin/agda`.  Its data
directory is the Cabal installation path baked in at compile time
(`.stack-work/install/.../share/.../Agda-2.9.0`), so this binary is not
relocatable; it depends on the source tree's `.stack-work` directory
staying in place.
